# SOLSTICE Cover Lab

![make.fun bounty](https://img.shields.io/badge/make.fun-gta6--cover--art--01-ff2e88)
![entrant](https://img.shields.io/badge/entrant-tapetelo-22d3ee)
![repo](https://img.shields.io/badge/repo-gta6--cover--art--01-ffe95e)

SOLSTICE Cover Lab is an offline, multi-panel cover maker: add 1–5 of your own photos, spread them across five panel layouts (Hero 5, Triptych, Grid 6, Diagonal, Quad), grade them with four sunset/neon colour grades, set huge gradient lettering, and export a shareable PNG in 1080×1080, 1080×1350, 1920×1080 or 1200×1600. Every panel can be cropped and panned by hand, one photo can fill every panel with different crops, and the palm silhouettes, sun disc, halftone dots and grain are all drawn in code — no game artwork, logos or fonts are used. Photos are read on your own machine and never uploaded; the app makes no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Add your photos (or press “Try pier sample”), pick a layout and a grade, type your title, and press **Download PNG**.
